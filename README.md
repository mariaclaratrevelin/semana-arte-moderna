# 🎨 Semana de Arte Moderna de 1922

## 📝 Sobre o projeto

O projeto **Semana de Arte Moderna** consiste no desenvolvimento de uma página web inspirada em uma obra apresentada durante a Semana de Arte Moderna de 1922, evento marcante para a história da arte e da cultura brasileira.

A proposta foi criar uma página que apresentasse informações sobre a obra escolhida e seu autor (Boêmios - Di Cavalcanti), explorando elementos visuais que transmitissem a identidade artística do período.

O projeto foi desenvolvido com o objetivo de colocar em prática os conhecimentos adquiridos sobre **teoria das cores, tipografia e estilização de páginas web**, utilizando HTML5 e CSS3.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação do conteúdo e dos elementos da página.
- **CSS3:** estilização, aplicação de cores e personalização da tipografia.

## 📂 Estrutura do projeto

```text
semana-arte-moderna/
├── fonts/
│   ├── verve.ttf
│   └── typewcond_regular.otf
├── images/
│   └── boemios.jpg
├── index.html
├── style/
│   └── style.css
└── README.md
```

## 📄 Descrição dos arquivos

- `index.html`: arquivo principal, responsável pela estrutura e pelo conteúdo da página.
- `style/style.css`: arquivo responsável pela estilização e pela apresentação visual do site.
- `fonts/`: diretório que contém as fontes utilizadas na página.
- `images/`: diretório que armazena a imagem da obra escolhida.
- `README.md`: documento com informações sobre o projeto.

## 🚀 Como executar o projeto

1. Clone este repositório ou faça o download dos arquivos.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em seu navegador.
4. Explore a página e conheça a obra e seu autor!
